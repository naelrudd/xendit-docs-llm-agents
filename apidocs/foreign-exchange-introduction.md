# Introduction

**Foreign Exchange**<small class='article-version'>1.0</small>
									
										
										

This Foreign Exchange API consists of quotes & conversion. A created quote returns a conversion rate that is active for a certain period of time. A created conversion acts on an active rate to convert from one currency into another.
